# CutFlow 0.3 验收记录

验证环境：2026-10-15，Windows x64，Rust 1.93.1。以下区分自动测试和真实服务验收。

## 自动验证

- 工作台 17 项测试通过：动态模型、OpenAI 多模态流式请求、视频地址拼接、断流结果未知、额度不足、提交前取消、媒体下载不发送密钥、损坏状态拒绝覆盖、任务幂等与重启不重发、控制令牌、参考图签名、中文字幕分句、单写入者锁、保存失败回滚、MCP 参数定义、工程素材复制与去重，以及真实引擎的入点裁剪和一次撤销。
- 下载器 18 项 Windows 测试通过：实际 UHD 尺寸规则、队列操作、取消、重复请求、中断恢复、凭据保护与 DPAPI 读回。
- 完整 Slint 应用树编译通过；原生下载协调器夹具编译通过；回调注册检查通过。
- 原生剪辑引擎 114 项回归测试通过，覆盖旧格式、撤销重做、失败批量原子性、多轨、分割和时间参数。完整编辑器类型检查已通过。按用户要求停止本地优化编译，完整 ZIP、Setup 与启动验收交由 GitHub Actions 执行。

## 待真实服务验收

- B站扫码等待、手机确认、二维码过期、登录失效；会员与非会员可见画质、真实严格 4K 下载、限流。
- 已有 Flow2API 服务的模型、额度、参考图、图片和视频实际生成、真实断流与后端取消行为。
- 中文 Kokoro 下载及实际音质，Whisper 模型下载及实际字幕同步。
- AI 与人工交替编辑、工程切换、保存重开，混合素材的实际导出尺寸、音轨和切点。
- 安装、卸载、高 DPI 和常用电脑显卡的窗口回归。启动冒烟检查不能代替实际剪辑验收。

## 已知限制

- 模型列表协议不包含完整能力描述；图片/视频分类、比例、参考图数量和时长提示主要从模型名称推断，可手动填写兼容模型 ID。具体支持以服务为准。
- 字幕按配音分句真实时长安排，不是逐字强制对齐。短视频素材不足时报错；不静默重复或极端变速。
- 任务恢复保留检查点并显示中断，不会自动继续未完成的云端提交。客户端预算限制提交次数，不能控制 Flow2API 内部重试。
- 关闭外部 AI 不关闭软件；关闭 CutFlow 本身会结束本地任务，重启后显示中断。
- 工程媒体保存在工程内，但工程文档沿用绝对路径；迁移目录后可能需重定位。DPAPI 仅支持原 Windows 用户。
- 导出需要用户确认。安装包没有代码签名、自动更新或签名更新服务。
- ffprobe 检查结构和轨道不能保证每一帧都无损坏；真实导出仍需播放核验。
- 清理仅针对确认无用的本轮测试文件，媒体、配置、模型和未核查任务不能当作缓存清理。
