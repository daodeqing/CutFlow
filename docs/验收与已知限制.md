## Windows 云端启动修复（2026-10-15）

- Actions #4（提交 `5c2f10a`）已完成全部编译，但打包启动验收失败：Windows Server 的 Microsoft Basic Render Driver 属于 CPU 适配器，WGPU 在配置窗口表面时报告 `Failed to wait for GPU to come idle before reconfiguring the Surface`。
- CPU 适配器或设备不可用时，窗口明确选择 Slint 软件渲染，预览使用现有 CPU 合成路径；硬件 GPU 继续共享 WGPU 设备。可设置 `CUTFLOW_RENDERER=software` 绕过 GPU 初始化，用于有驱动问题的电脑。
- 构建保留真实编辑、幂等、冲突、撤销重做、保存重开及回环控制队列冒烟测试，并分别验证自动选择与强制软件渲染下的正常窗口启动。失败日志随诊断产物上传。
- 本次完整 Windows 编译及两种窗口启动的结果以新 Actions 为准，推送时尚未完成；真实显卡、账号与付费生成验收仍需单独进行。

## 已知限制

- GFlow 项目控制目录提供固定账号的模型能力；手填未知 GFlow ID 仍显示能力未确认。具体额度和上游可用性以 Google 实际响应为准。
- 字幕按配音分句真实时长安排，不是逐字强制对齐。短视频素材不足时报错；不静默重复或极端变速。
- 任务恢复保留检查点并显示中断，不会自动继续未完成的云端提交。客户端预算限制提交次数，不能控制 Flow2API 内部重试。
- 关闭外部 AI 不关闭软件；有任务时关闭主窗口转入托盘，明确退出才停止本地任务，重启后显示中断。主窗口和编辑器分别关闭。
- 工程媒体保存在工程内，但工程文档沿用绝对路径；迁移目录后可能需重定位。DPAPI 仅支持原 Windows 用户。
- 导出需要用户确认。安装包没有代码签名、自动更新或签名更新服务。
- ffprobe 检查结构和轨道不能保证每一帧都无损坏；真实导出仍需播放核验。
- 清理仅针对确认无用的本轮测试文件，媒体、配置、模型和未核查任务不能当作缓存清理。
