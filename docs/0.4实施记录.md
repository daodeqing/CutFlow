# CutFlow 0.4 实施与验证

目标：BDL 原生 Vue/Tauri 主窗口、独立 Concat 剪辑器和 OpenAI Chat Completions 图片/视频创作。

实施顺序：账号与状态隔离 → 主窗口与素材交接 → 兼容生成与故障恢复 → Windows 双窗口构建与启动验收 → GitHub 交付。

本地源码来源为 `D:\LUO\bilibili下载器\bdl-main`，只读。快照校验记录在 `bdl-source-snapshot.json`。个人设置、凭据、依赖与编译输出不属于源码快照。

本地 BDL 当前为 0.8.4；仓库引用包含同源完整界面与下载功能的 0.8.5，以及此前加入的网络诊断、日志脱敏和文件保护修复。本轮保留这些修复，快照记录明确列出与本地来源的差异，未将两个版本描述为逐字相同。

软件关闭独立于 AI/MCP 客户端。主窗口负责 BDL 与生成，编辑器在独立进程和 `portable/editor` 下持有控制任务与锁。素材仅在用户确认工程后导入素材库。

真实 B站登录、会员画质和 Flow 生成需用户在软件配置后验收；模拟测试不代表真实账号服务验收。

本地验证：前端生产构建、266 项前端测试及新增页面 ESLint 通过；BDL 后台 128 项通过、6 项按原条件忽略；工作台 21 项通过。主窗口 Rust 编译、真实窗口可见及正常退出、进程级模拟生成服务验收通过。完整 Slint 树及原生协调器夹具编译通过；239 个回调注册检查通过。独立剪辑器及完整包在 GitHub 编译验证。
