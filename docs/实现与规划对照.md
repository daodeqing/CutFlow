# 实现与规划对照

本版本实现规划 P0 阶段的集成路径，未宣称完成原方案估算的 16–26 人周工作。

| 规划内容 | 当前实现 |
|---|---|
| 保留原生剪辑内核 | 完整 Concat 源码快照，新增 Slint 面板，不改为网页剪辑器 |
| 分开构建编辑器与下载工作区 | editor 与 reference/bdl 独立 Cargo 工作区；downloader 为小型适配库 |
| 下载服务 | 采用 P0 的 BDL CLI 子进程适配，不是已提取的 bdl-core 常驻服务 |
| 严格 4K | qn120 + missing-quality=skip；ffprobe 核验实际 UHD 尺寸与音视频轨 |
| 分 P 与批量 | 每条任务手选分 P，多个任务串行；暂不实现收藏夹或 UP 主批量入口 |
| 队列与恢复 | 原子 JSON 队列、文件锁、上游检查点；重启手动继续；不是 SQLite 服务 |
| 凭据 | Windows 当前用户 DPAPI；环境传给子进程；无二维码登录 |
| 资产交接 | 资产清单、目录白名单、媒体探测；与目标工程绑定 |
| 当前会话入库 | Studio.apply(Command::Batch) 后 Session.save，再确认任务；不调用外部 API 写当前工程 |
| 幂等 | 按目标工程路径与规范化媒体路径核对；工程已保存但队列未保存时可重放 |
| 媒体指纹 | 当前为绝对路径 + 文件大小；尚未实现完整内容指纹和跨目录去重 |
| 来源 | 清单保留链接、分 P、任务 ID、画质策略和授权备注；作者信息未统一建库 |
| 代理与字幕 | 保留上游实现；尚未做该修改版完整规格回归与字幕交换补齐 |
| 暂停 | 停止进程树并保留检查点；未完成单个文件的字节级断点取决于 BDL 现有能力 |
| 进度 | 显示任务状态，不伪造百分比；尚无实时字节速率/剩余时间 |
| 安装 | 提供便携 ZIP 构建、可选 Inno Setup、DLL 组装和启动检查；未在本环境执行 |
| 自动更新与签名 | 未实现；开发版不静默更新，不附带签名证书 |
| 安全与格式校验 | 用户目录、无 shell 拼接、敏感输出不落盘、原子队列保存；尚未做渗透测试或完整媒体模糊测试 |

## 后续应先完成的验收

先运行 Windows 流水线和实机测试，修复构建或启动阻断问题，再验证真实授权 4K 下载、两段剪辑、保存恢复与母版导出。验收通过后，才扩大到 bdl-core 常驻服务、SQLite 素材库、完整媒体指纹、附件下载、代理切点和字幕补齐。编辑器无法满足实机基本链路时，按原规划重新评估 Shotcut 路线。

## 修改入口

- `editor/src/crates/concat/src/downloads.rs`：当前会话协调、队列单写者、后台工作与入库确认。
- `editor/src/crates/concat/ui/dialogs/downloads.slint`：原生下载面板。
- `editor/src/crates/concat/src/lib.rs`：生命周期与窗口绑定。
- `editor/src/crates/concat/ui/app.slint`、`ui/title-bar.slint`：面板与入口。
- `downloader/src/lib.rs`：策略、持久化、BDL 协议、探测与清单。
- `downloader/src/process.rs`：进程启动、取消、输出限制与超时。
- `downloader/src/credentials.rs`：DPAPI。
- `scripts/Build-Windows.ps1`、`Prepare-Windows.ps1`：Windows 构建与依赖。
