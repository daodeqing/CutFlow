# CutFlow 0.2 UI 与按钮行为

本次继续完善原生 Slint 界面和任务协调器。编辑器的媒体解码、复杂时间线、字幕和导出继续使用上游；本次没有宣称已经验收这些全部上游按钮。

## 界面

左侧为链接、分 P、画质、用途备注和解析结果；右侧为状态统计、队列操作、搜索筛选与任务卡片；底部为结果提示、账号凭据和组件状态。空间不足时可滚动查看完整面板。颜色沿用编辑器主题。

任务模型仅在任务、筛选或工程上下文变化后更新。计时状态仍每 250 毫秒刷新，但不再因此重建任务卡片，避免点击、滚动和焦点被周期性打断。

## 按钮状态

| 按钮 | 可执行条件 | 行为 |
|---|---|---|
| 解析可用画质 | 无后台任务、组件存在、合法来源 | 独立解析；Enter 可触发 |
| 取消解析 | 当前解析尚未结束 | 停止所拥有的解析进程，忽略晚到的成功结果 |
| 加入下载队列 | 当前有工程、组件就绪、合法链接和分 P、用途已填 | 绑定当前工程并持久化；Ctrl+Enter 可触发 |
| 暂停 | 排队或下载中 | 仅暂停指定任务，不停止其他队列任务 |
| 继续 / 重试 | 暂停、失败或取消；同一任务没有仍在停止的工作 | 恢复已完成素材，或利用原检查点重新排队 |
| 全部暂停 | 有排队、下载或解析工作 | 暂停所有待下载任务，停止当前网络工作，保留文件 |
| 继续队列 | 有暂停/等待继续任务，组件可用 | 继续等待任务，失败和已取消任务保持原状 |
| 取消 | 指定任务尚未完成入库 | 经面板内确认取消；不删除任何已下载文件 |
| 导入素材 | 完成文件待入库、当前为绑定工程、后台空闲 | 再探测母版，经当前窗口命令入库，工程保存后确认 |
| 切换到工程 | 待入库任务属于其他工程，后台空闲 | 先保存关闭当前工程，再打开绑定工程；保存失败则拒绝切换 |
| 文件夹 | 任务目录已经创建 | 在文件管理器打开任务媒体目录 |
| 移除记录 | 已入库、已取消或失败，并且此任务没有后台工作 | 确认后仅移除任务记录；保留文件和工程引用 |
| 新建 / 打开工程 | 后台空闲 | 保存当前编辑，再使用已有原生工程入口 |
| 保存凭据 | 存储可写、后台空闲、输入非空 | Windows DPAPI 加密保存；输入框随后清空 |
| 退出账号 | 已有凭据、后台空闲 | 确认后仅删除凭据，保留本地素材 |
| 检查组件 | 后台空闲 | 本地启动 bdl、ffmpeg、ffprobe 获取版本，不请求 B站 |
| 组件目录 | 任意状态 | 打开组件目录；未创建时打开程序目录 |
| 返回剪辑 / 关闭 | 任意状态 | 关闭面板，后台任务按既定状态继续；清空凭据输入框 |

## 修复的行为

- 取消一个排队任务不再悄悄暂停整条队列。
- 同一视频的 BV 号和普通视频 URL 按同一来源识别；重复分 P 顺序不再绕过重复任务检查。
- 下载已完成但暂停消息晚到时，保留完成媒体，用户继续后直接进入校验入库。
- 已取消任务不会因为后台成功结果晚到而自动变成已完成。
- 失败暂停的队列添加新任务后保持暂停，不自动重试失败任务。
- 暂停/取消与恢复、移除的可用状态在 Rust 后端再次检查，不能仅通过调用回调越过界面禁用状态。
- 后台工作意外退出时结束忙碌状态并给出可操作提示，不无限显示处理中。
- 下载面板打开时，时间线播放、分割、撤销、粘贴、导出等编辑快捷键停止接管；表单文字输入继续工作。
- 原生窗口的 blur 入口会将焦点留在打开的下载面板。Escape 先关闭面板内确认区，再返回编辑器。关闭面板清空尚未保存的凭据文本。
- 新建任务文件锁在读取队列前获取，避免启动快照与其他实例并发写入。

## 当前边界

状态、队列动作、界面定义和回调协调器的可执行测试不等于完整 Windows 编辑器实测。原生回调测试使用模拟媒体宿主，明确不验证上游解码器、GPU 或真实 B站账号权限；Windows 安装和媒体回归仍需完成。
