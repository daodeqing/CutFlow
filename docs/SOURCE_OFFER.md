# 对应源码随附要求

这是开发版工程的发行说明，不是远程下载承诺。

如果你将构建的 CutFlow 二进制提供给他人，请同时提供用于该构建的完整 CutFlow 源码压缩包，包含 editor、reference/bdl、downloader、scripts、Cargo.lock、upstreams.lock.json 与许可证，并记录你的后续修改。不要只提供上游首页链接。

外部原生依赖按 editor/scripts/ci/deps.lock 取用。对外分发前，还需按各组件许可提供它们的对应源码、构建配置及其他所需材料；本源码工程没有包含所有预编译依赖的源码，也未完成该环节的发行审计。不要仅凭脚本能打包就认定可以直接公开发行。

程序无更新服务、遥测上传或用户云素材服务。未来增加服务或改变分发方式时，应重新审查许可和安全边界。
