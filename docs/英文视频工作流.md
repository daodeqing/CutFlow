# 英文视频工作流（预览）

在 CutFlow 的 B站工作区打开「英文制作」。填写视频链接或选择已完成的下载，确认拥有下载、翻译和发布权限，选择模型后开始制作。链接默认处理第一个分 P；可选择 720p、1080p 或可用最高画质。下载和英文成片分别保留，需预留两份视频空间。

字幕优先使用视频的独立字幕；没有时选择兼容音频输入的 AI 服务，或本地 Whisper。字幕、弹幕、语音和文案可以分别指定模型；默认沿用 AI 设置里的地址和密钥，模型名可手动填写。模型代理可能转发到云端并产生费用。首次选择本地 Whisper 时才下载所选模型到 portable/whisper-models，tiny 约 74 MiB，base 约 141 MiB，small 约 465 MiB。

软件按时间段稀疏筛选并翻译文字弹幕。可选深色字幕条遮挡画面底部约 14% 的原字幕，避免原来的拉花，但会遮住该区域；其他位置的烧录文字仍可能保留。取消该选项可保留原画。已完成的视频不会自动重做，生成后务必检查字幕、弹幕和画面。模型选择支持点击列表或直接输入名称。

可以监控指定收藏夹或 UP 主空间：首次记录当前内容，之后大约每小时检查新增内容并排队。CutFlow 必须保持运行或驻留托盘；完全退出时暂停。上次位置找不到时会提示核查并停止检测，避免误处理旧视频。

文案会根据视频标题和英文字幕生成简短的英文开头；可以选填与视频相关的 X 话题，但软件不自动查询 X 实时热榜。成片附带独立的视频英文简介和 X 推文；可填写具体修改要求并单独重新生成两者，不需要重做视频。审核后可用默认浏览器打开带文案的 X 发帖页，或复制指令给 Cindy 协助上传；上传能力取决于 Cindy 浏览器授权和 X 登录状态，最终发布由用户确认。也可打开 CutFlow 内置的 X 窗口手动上传。Cindy 的 X 机器人连接不代表个人发帖权限。视频时长、文件大小和上传权限由 X 及账号决定。
