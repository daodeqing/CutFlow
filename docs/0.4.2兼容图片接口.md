# CutFlow 0.4.2

- 保留 GFlow；进入图片创作时，优先选择已配置的 gpt-image-1.5 兼容图片模型，其他 gpt-image 模型作为可选项。用户明确选择的模型不会被后台刷新覆盖。
- GFlow 同步成功只代表登录状态更新。Google 异常活动拒绝仍可能发生；选择兼容图片模型是用户操作，不会在失败后静默换模型重发。
- 实际兼容接口单张图片已生成并由 CutFlow 保存。该接口返回比例未遵守请求，界面据真实宽高提示偏差，保留原图，不自动裁剪或增加生成费用。
- 模型标识与 OpenAI 兼容格式不证明服务商的上游来源、授权、价格或参数完整性。图像数量、尺寸和画质以实际回执为准。
