## v0.8.1 · 弹幕字幕转换

- 弹幕新增 SRT 与 ASS 输出。在“设置 → 下载预设 → 编辑 → 转换 → 弹幕格式”选择，下载完成后自动生成独立字幕文件。
- SRT 按普通字幕显示；ASS 保留普通弹幕的滚动方向、颜色以及顶部/底部固定位置，方便作为字幕加载到支持对应格式的播放器。
- 转换时保留弹幕在视频内的出现时间，支持中文与 XML 实体解码。HTML、SRT、ASS 均可额外保留原始 XML，现有 XML 与离线 HTML 输出保持兼容。
- 完善格式保存、任务快照与产物清单，并使用三条真实公开视频验证实际下载、媒体合并、SRT/ASS 转换、时间对应及中文渲染。

SRT 不支持滚动弹幕，密集时段可能堆叠占据画面；需要弹幕效果时建议选择 ASS，并使用支持 ASS 特效的播放器。高级、脚本与 BAS 弹幕不转换。Kodi/电视真机兼容性尚未逐设备验证。

macOS 安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开可在 Finder 中按住 Control 点击应用并选择“打开”，或到“系统设置 → 隐私与安全性”选择“仍要打开”。
