## v0.7.0 · Android 平板适配

- Android 新增平板、横屏及分屏布局，根据可用窗口切换侧栏或底部导航，并调整字体、控件和列表密度，提升大屏的内容利用率。
- 解析、内容库和传输列表统一卡片、行内留白及可辨识封面；优化长标题、两列索引和长列表滚动，避免 checkbox、封面与文字挤在一起。
- 内容库和传输页面统一为 Tabs 与右侧常用工具栏，复用搜索、筛选及管理多选；窄手机窗口也能清晰显示标签和数量。
- 解析首页改为简洁的居中输入表单，粘贴与解析范围放在上方，保留输入和解析按钮；平板限宽，手机接近全宽。
- 手机操作面板在平板上改为限宽居中弹窗；完善短窗口、安全区及横竖屏切换时的滚动与草稿保留。
- 设置按功能拆成独立卡片，优化平板多列参数布局；修复新增预设字段间距及“内容 / 转换 / 封装”分页的选中样式、下划线和触控悬停状态。
- 修复 Android WebView 最小字体限制导致的界面比例失衡，保留系统字体缩放。
- 修复外观菜单悬停提示的乱码。
- 修复长标题视频在 Android 分段下载时的临时文件问题，增加拼接长度校验；重试时重新下载无效媒体轨道，并补齐移动端失败任务的重试入口。
- 整理桌面与移动端页面目录，共享业务状态与基础组件，让两端界面可以独立维护。

本次以 Android 平板体验为主要更新，同时保留手机与桌面端流程。Android 暂不支持字幕和封面嵌入，可在预设中保存独立文件。
