## v0.6.5

- 修复 B 站 JSON 字幕无法嵌入的问题：支持转换为 SRT 或 ASS，转换失败时显示具体原因。
- 修复 MKV 封面嵌入：JPEG/PNG 以带文件名和 MIME 信息的封面附件写入。
- 传输列表默认最新在前：已完成按完成时间排序，其他列表按添加顺序排序。
- 整理媒体设置和下载弹窗：常规只放目录、命名和重名处理；媒体区分视频、音频、封面、字幕、弹幕，下载字幕/弹幕后展开格式选项；勾选嵌入自动使用 MKV。
- “音视频”改为“音频+视频”；记住下载内容、输出和附件偏好。
- 仅音频可选择不转换（m4s）或转为 MP3，原始音频无需 FFmpeg，MP3 进行真实转码。
- 字幕可保存 SRT/ASS 并嵌入 MKV，弹幕可保存 XML 或支持本地视频同步的离线 HTML。
- 嵌入和独立保存分别选择，只嵌入时会获取所需素材并在成功合并后清理临时素材；兼容已有配置和任务。
- “移除”改为“删除任务”，明确仅删除任务记录、保留下载文件；批量操作和删除已完成任务使用相同措辞。
