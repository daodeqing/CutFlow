## v0.7.1 · 任务移除与文件清理

- 修复移除任务后残留 `.bdlpart`、分段和下载状态文件的问题。移除前先停止并等待下载、合并或导出结束，保留已生成的成品文件。
- 新增“删除任务及文件”，支持单个任务和选中任务批量操作。删除前展示文件路径、数量和大小，确认后按任务归属删除，不递归删除下载目录。
- “清理临时文件”增加预览与确认，可回收已移除任务留下的孤立分段和辅助文件，并保护现有任务与无关文件。
- 完善暂停、续传、失败、计划任务及合并中的移除处理；文件发生变化时要求重新确认，避免使用过期预览删除新文件。
- 删除遇到文件占用、只读、权限不足、离线磁盘或 Android 目录授权失效时，保留任务记录并显示具体原因，便于解除问题后重试。
- 桌面、Android 手机和平板共用删除确认流程；优化窄屏批量操作栏，避免按钮挤压。

修复 #7。普通“移除任务”保留成品；“删除任务及文件”会删除预览中确认的任务文件，请核对后操作。若删除中途遇到错误，未移除的任务记录仍保留，界面会提示部分文件可能已清理。

macOS 安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开可在 Finder 中按住 Control 点击应用并选择“打开”，或到“系统设置 → 隐私与安全性”选择“仍要打开”。
